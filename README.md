# HidzStreaming

HidzStreaming is a Next.js + React + TypeScript streaming hub branded for HIDZPROJECT.

## Sections

- HIDZ ANIME
- HIDZ COMIC
- HIDZ DONGHUA
- HIDZ DRACHIN
- HIDZ MOVIES
- HIDZ YOUTUBE
- HIDZ TV

## Stack

Next.js App Router, React 19, TypeScript, Tailwind CSS 4, Lucide, and native HTML5 video playback.

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

The project is designed for Vercel. No required environment variables are needed for the base UI; the upstream catalog endpoints are handled server-side and cached where possible.
